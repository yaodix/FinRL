## 技术要求

## 语言与运行环境

1. Python 3.10 或 3.11
2. 研究与训练环境优先 Linux
3. 若后续接入 QMT，执行环境通常需要 Windows 主机

## 核心依赖

1. pandas
2. numpy
3. pyarrow
4. stable-baselines3
5. gymnasium
6. torch
7. matplotlib
8. optuna
9. mlflow
10. tickflow  # 获取数据

## 建议依赖

1. pydantic，用于配置校验
2. PyYAML，用于配置文件
3. loguru 或标准 logging，用于结构化日志
4. streamlit，用于 MVP 可视化
5. requests，用于飞书 webhook 推送

## 工程要求

1. 所有关键参数必须配置化，不允许硬编码在训练脚本中。
2. 训练、回测、推理三条链路必须共享同一份核心配置定义。
3. 数据、模型、日志和报表的目录结构必须稳定。
4. 每次运行必须可追溯到代码版本、数据版本和参数版本。

## 兼容性要求

1. 与现有 FinRL 仓库共存，但 ETF T0 项目逻辑应相对独立。
2. 不强依赖 FinRL 当前的多标的股票环境和 Alpaca 交易路径。
3. 能在不接入 QMT 的情况下完整跑通研究和仿真闭环。

## 测试要求

至少包含以下测试：

1. 数据校验与清洗单元测试
2. 特征构建单元测试
3. 环境状态转移测试
4. 回测一致性测试
5. 风控规则测试
